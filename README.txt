Cómo publicar en GitHub Pages:
1. Descomprime el archivo ZIP en tu computador.
2. En el repositorio de GitHub, entra a Add file > Upload files.
3. Sube index.html y la carpeta assets completa (no subas solo el ZIP).
4. Confirma el commit.
5. En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta /(root).
6. Guarda y espera a que GitHub Pages publique el sitio.
